# LivingAgentUniversity (LAU)

A playful, open-source living campus for **visualizing simulated AI agent work** and, eventually, connecting governed real agents.

> **Current state:** New repository bootstrap. The interactive React campus is being developed in a pull request. No real agents or external services are connected by default.

**Origin:** The BotTown + BotOffice idea. Original characters include Forge, Coherence, Scout, Rook, Nyx, and VaultBot.

**Principle:** Ledger above ego. Simulated results must never be mistaken for verified real-world actions.
